插上 USB，
直接安裝 Codex Micro。

不用安裝 ESP-IDF，也不用輸入燒錄指令。使用桌面版 Edge 或 Chrome，就能將 Cardputer ADV 變成 Codex 控制器與 USB 麥克風。

WEB INSTALLER

Codex Micro 1.0.0

準備就緒

此瀏覽器不支援網頁燒錄。請改用 Windows 桌面版 Microsoft Edge 或 Google Chrome。

網頁燒錄需要 HTTPS。請從正式 GitHub Pages 網址開啟本頁。

安裝會清除 Cardputer ADV 目前的韌體與設定。僅支援 ADV （StampS3A／ESP32-S3），不支援原版 Cardputer。

INSTALL IN FOUR STEPS

四個步驟完成燒錄

  1. 01

    確認硬體

    只使用 M5Stack Cardputer ADV 與可傳輸資料的 USB-C 線。

  2. 02

    進入下載模式

    按住 G0，再按一下 Reset；Windows 偵測到連接埠後放開 G0。

  3. 03

    開始安裝

    按「連接並安裝」，選擇新出現的 USB／COM 裝置並確認安裝。

  4. 04

    重新啟動

    完成後不要按 G0，按一下 Reset；LCD 亮起即代表安裝成功。

AFTER INSTALL

接上 Codex，立即使用。

USB 連接時，Windows 11 會看到 Codex 控制介面與 Cardputer ADV Microphone。需要無線控制時，可在藍牙設定配對 Codex Micro。
